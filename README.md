## About

Bubble Bliss aims to capture the joy and vibrant culture of bubble tea through a visually appealing and user-friendly website. This project was developed to practice and demonstrate proficiency in core front-end technologies, including HTML, CSS, and JavaScript.

The site features a welcoming homepage, a detailed “About Us” section expressing the brand’s story and passion, a contact form for customer interaction, and an embedded Google Map to help customers locate the shop. It perfectly blends aesthetics with functionality, delivering a seamless browsing experience across devices.

---

## Features

- **Responsive Navigation Bar:** Intuitive menu with icons for quick access to sections  
- **Engaging Hero Section:** Eye-catching promotional banner with enticing tagline  
- **About Us:** Brand story that connects with visitors and shares the shop’s mission  
- **Contact Form:** Simple and clean form for users to reach out (front-end only)  
- **Embedded Google Maps:** Interactive map showing the shop’s physical location  
- **Business Info:** Clear display of address and opening hours for convenience  
- **Modern Design:** Clean typography and layout optimized for desktop and mobile
